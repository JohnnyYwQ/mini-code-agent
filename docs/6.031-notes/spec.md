### Specification Structure

## Signature

- function name
- input name
- input type
- output type

## Require clause

 precondition的一部分对input参数的限制比如x > 0

## Effect clause

- 返回值是什么
- 什么时候抛异常
- 会不会修改传入参数
- 会怎么改

在满足preconditon的情况下，会产生的行为

## Test

test 本身就该测precondition成立的条件下的东西

## Side effect

对可变对象的修改
