# Persist and resume Conversations

Conversations are durable and can be reopened with their previous turns. CLI creates a new Conversation by default and may resume only Conversations in its current Memory Space. Web lists every Conversation owned by the local User, groups Conversations from the same Memory Space together in its sidebar, and supports browsing or switching across workspaces; each Conversation stores a title derived from its first user query, while display labels compose that title with the Memory Space's workspace path rather than copying the path into the title. Ephemeral process-global chat history is not the product state. The persisted transcript stores each top-level agent message as its own ordered record and retains complete content, including tool-use and tool-result blocks; Web renders only user-visible text, while Memory receives a normalized string-only subset derived from that transcript. A submitted user message is persisted before the agent runs, generated messages are persisted only after a successful run, and a failed run leaves the user message unanswered without retaining a partial agent transcript or triggering an automatic retry.
