# Extract Memory from recent Turns

Memory ADD is exposed to the outer LLM as a no-argument `remember` tool that it may invoke during the current Turn. The trusted tool handler, rather than model-generated arguments, supplies the Memory Context and a rolling extraction window containing normalized visible text from at most the five most recent completed Turns plus whatever visible content already exists in the current Turn, at minimum the user query; tool activity is excluded. The extractor LLM may create Memory from any content in that window, while the prompt tells it to avoid semantically equivalent existing Memory, prefer newer explicit statements, and ignore statements superseded or contradicted by later Turns; target-Scope hash deduplication remains the final exact-match guard. A `remember` failure is returned to the outer LLM as a non-fatal tool error so the current Turn can continue, and any earlier successful writes from the non-atomic add remain stored.
