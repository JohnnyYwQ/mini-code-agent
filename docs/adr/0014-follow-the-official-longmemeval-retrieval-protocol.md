# Follow the official LongMemEval retrieval protocol

The LongMemEval Retrieval Baseline runs this project's E5, BM25, reciprocal-rank-fusion, and BGE retrieval variants over the pinned official cleaned LongMemEval-S data while following the official retrieval implementation's session indexing, user-only text, case eligibility, and `@5`/`@10` scoring rules. Abstention and cases without user-side target evidence remain in raw artifacts with exclusion reasons but do not contribute to aggregate retrieval metrics. Reader-LLM generation, answer judging, assistant-side retrieval coverage, the official repository's retriever models, and claims of an official leaderboard score are outside this baseline; ADR-0011's role-complete variant is superseded so the primary baseline stays comparable to the official retrieval experiment.
