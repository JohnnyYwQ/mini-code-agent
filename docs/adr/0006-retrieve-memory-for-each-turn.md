# Retrieve Memory for each turn

Before each outer-LLM Turn, the agent runtime automatically calls a context-aware Memory recall using the latest user query and the trusted Memory Context, then supplies the results as temporary system context. Recall searches User Memory and the current Space Memory, combines them into at most five results, preserves each result's Scope label, and prefers User Memory when identical Source Text is visible in both Scopes. Retrieved Memories are recomputed for every Turn and are not persisted in the Conversation transcript, because they are a relevance-based projection rather than part of the Conversation's authoritative history. If retrieval infrastructure fails after the trusted context has been resolved, the failure is logged and the Turn continues without Memory context; failure to resolve the local User, Conversation, or Memory Space remains fatal and prevents the agent from running.
